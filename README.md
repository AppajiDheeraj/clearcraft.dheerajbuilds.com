## What is included

## Stack

- Next.js 16
- React 19
- TypeScript
- Vercel, connected to this GitHub repository
- Cloudflare DNS for the custom domain

## Run locally

```bash
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000).

## Validate a production build

```bash
npm run lint
npm run build -- --webpack
```
